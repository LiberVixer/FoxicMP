# FoxicMP: работа с тремя редакциями

## Продукт и источники

- Общий проект — FoxicMP. Windows Classic: FoxicMP Classic (MFC/DirectShow).
  Windows Qt и Linux Qt: FoxiqMP qt (один `qt/` с платформенными адаптерами).
- Актуальные сравнение и порядок работ:
  `docs/FoxicMPFamilyMatrix.md`, `docs/FoxicMPFamilyPlan.md`.
  `docs/LinuxParityPlan.md` сохраняет историю прежних Linux-этапов.
- Для запроса об общей функции рассмотреть все три редакции и реализовать
  применимые изменения вместе. Если пользователь явно указал платформу,
  соблюсти его границы. Отличие движка оформлять как конкретную границу,
  не как повод объявить отсутствующую функцию готовой.
- Общий Qt-код менять один раз. Classic↔Qt перенос работает в обе стороны.
  Не объединять EXE, INI, IPC endpoints, ProgID или регистрацию приложений.

## Поведение и совместимость

- Сохранённые настройки пользователя выше новых defaults. Не нормализовать
  существующие профили автоматически. Общие defaults относятся к новым профилям.
- OSD по умолчанию выключено; положение окна запоминается; ограничение
  пропорций окна по видеокадру выключено. Пропорции самого видео — другой параметр.
- Сохранить независимые логотипы/названия редакций и #LiberVixer.
- Сохранять действующие CLI/API и форматы через совместимые адаптеры.
  YouTubeHarvester не менять в задачах плеера без прямого запроса.
- Меню/команды должны отражать фактическую поддержку платформы и состояние.
  Выбор параметра libmpv не является доказательством наличия GPU/HDR/устройства.

## Проверка и установка

- Проверять применимые изменённые сценарии каждой затронутой редакции;
  результат Linux не выдавать за Windows-проверку. Сохранять точный exit code.
- Для тестов использовать отдельные профили. Linux UI/audio: `qt/tests/run_tests.sh`
  с частными X11/D-Bus/PulseAudio. Не менять микшер/мониторы/сеанс рабочего стола.
- После каждой новой проверенной версии обновлять установленный Linux-плеер
  `_bin/FoxicMPQt-linux-x64`, сохранив прежний EXE для отката и INI/личные файлы.
  Заменять EXE атомарно; сверять версию и неизменность профиля при замене.
- Не останавливать просмотр ради замены файла. Windows-установки независимы:
  Classic `C:\FoxBroxer\Prg\FoxicMP`, Qt `C:\FoxBroxer\Prg\FoxicMPq`.
  Настройки установленных приложений не менять без соответствующего запроса.
  Не затрагивать MPC/MPC-BE и `C:\FoxBroxer\Prg\MPMY`.
- Для общих функций обновлять матрицу/результаты проверки. Документационные
  изменения не требуют bump версии, сборки или переустановки.
- Дисковые меню, аналоговое ТВ и физическое оборудование отложены пользователем;
  Wayland исключён из проверок. Не возобновлять их без запроса. Не создавать
  периодических таймеров. Временные одноразовые задачи тестов удалять после них.
