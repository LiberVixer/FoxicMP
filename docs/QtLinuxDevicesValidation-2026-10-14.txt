Реализация
==========
Диалог DVD/Blu-ray/Audio CD: дисковод, ISO, папка, DVD-заголовок (с 1),
самый длинный фильм, угол при открытии; MPLS для Blu-ray (0 зарезервирован
для автоматического выбора). Главы/дорожки/языки через существующие меню,
быстрый переход между главами, отдельный выбор фильма. CLI --dvd, --bluray,
--cdda, --disc-title. Нумерация DVD интерфейса преобразуется к 0-based
индексу libmpv; проверены разные заголовки с разной длительностью.

DVD/Blu-ray ISO и папки сохраняют позицию отдельно по заголовку. Физические
сменные диски не используют прежнюю позицию. Закрытие после перемотки
читает актуальную time-pos движка вместо отложенного уведомления Qt.
Во время открытия нового источника прежняя time-pos не сохраняется для него.
Открытый DVD-фильм ограничивается объявленной длительностью заголовка через
file-local-options/end: навигационные команды диска могут переходить к другим
фильмам или повторяться без EOF. Ограничение снимается при закрытии источника.
Проверяются естественное окончание, снятие лимита и действие после просмотра.

Диалог захвата: V4L2, PulseAudio/PipeWire, ALSA, генераторы видео/звука;
дополнительный аудиовход для видео выбирается явно. Прямые входы не
перематываются, не запоминают позицию и не выполняют действие после окончания.

DVB: выбор adapter/card, канал, импорт UTF-8 VDR/zap (до 1 МБ), поиск через
dvbv5-scan -a CARD -f 0 -I DVBV5 -O VDR -o OUTPUT INITIAL_FILE.
QProcess запускает аргументы напрямую, без оболочки. GUI остаётся доступным;
поиск можно отменить. Начальные частоты и результат сохраняются рядом с
программой. QSaveFile заменяет список только после успешного чтения;
отмена/ошибка сохраняют предыдущий список. Параметры настоящей команды
сверены с --help локального dvb-tools. Сам приём не проверен без тюнера.

Структурированные адреса foxicmp-device:// сохраняются в переносимом
профиле, M3U8, истории и избранном; путь ISO с кириллицей, пробелом и #
проходит round trip. Неверные/повторяющиеся параметры отклоняются.
Проверка поддержки protocol-list/demuxer-lavf-list и доступности устройства
выполняется до замены очереди. Обычные URL и progressive проходят регрессию.

Стенд и границы проверки
=======================
qt/tests/generate_dvd.py создаёт незашифрованный PAL DVD: два фильма
6/12 секунд, два раздела в каждом, MPEG-2 video, AC-3 48 kHz stereo.
dvdauthor и genisoimage создают структуру VIDEO_TS и ISO; физический диск
не монтируется и не изменяется. Существующий /dev/sr0 пуст; камеры и DVB нет.

Видеозахват проверяется реальным av://lavfi с кадрами и текущим временем.
Аудиозахват — av://lavfi:sine и отдельный monitor виртуального null sink
foxicmp_devices_011. PulseAudio API работает поверх PipeWire 1.0.5.
Отдельный PulseAudio-вход проверен также вместе с тестовым видеосигналом:
выбор в GUI, сохранение выбора, появление аудиопараметров в декодере.
Микрофон пользователя не записывается, системный выход не перенастраивается.
Все тестовые профили находятся в временных каталогах; профиль Windows не менялся.

Сканер проверяется подменным исполняемым процессом: параметры запуска,
успешное сохранение и отмена следующего поиска с сохранением старого списка.
Это проверка управления процессом/профилем, не аппаратного сканирования.

Остаются: интерактивное DVD-меню (удалено из mpv), Blu-ray-меню,
аналоговая настройка частот, защищённые Blu-ray, многоугловые диски,
физические DVD/CD, камера/карта захвата и DVB-тюнер. ALSA и Blu-ray имеют
проверяемые адаптеры/проверку возможностей, но их реальный сигнал на этом
стенде не подтверждён. OpenGL на физической видеокарте/Wayland не проверен.
GitHub workflow дополнен DVD-fixture и частным PulseAudio-monitor;
запуск на GitHub не выполнялся.

Основания API:
https://mpv.io/manual/stable/#protocols
https://raw.githubusercontent.com/mpv-player/mpv/v0.37.0/stream/stream_dvdnav.c
https://raw.githubusercontent.com/mpv-player/mpv/v0.37.0/stream/stream_cdda.c
https://mpv.io/manual/stable/#property-list
