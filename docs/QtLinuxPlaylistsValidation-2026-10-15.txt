Дата: 2026-10-15. Linux Mint 22.3 x64, Qt 6.4.2, libmpv 0.37.0,

Реализация
-----------
PlaylistPanel хранит именованные вкладки, стабильные UUID записей и исходный
порядок. Window отдельно хранит играющую очередь; действия со списком применяются
к открытой вкладке. Смена вкладки не останавливает mpv и не меняет автопереход.
Уничтожение играющей вкладки/записи сначала останавливает воспроизведение.
Сохранение playlist/tabsV1 в соседнем FoxicMPQt.ini; прежние files/playlist и
files/currentIndex сохраняются для совместимости. История/избранное/прочие
настройки сохраняются. Профиль Windows и интерфейс Harvester не изменялись.

Поиск по названию/пути, длительность в отдельной правой части строки, сумма
видимых известных длительностей и число неизвестных. Сортировки: название,
путь, создание, изменение, размер, длительность; числовое сравнение имён;
неизвестные значения после известных. Обратный порядок, перемешивание строк
и исходный порядок (сохраняется после перезапуска), перемещение мышью/кнопками.
Сортировка и метаданные не подменяют текущую запись и историю shuffle.

FFprobe запускается последовательно без блокировки интерфейса, только для
локальных обычных файлов. Тайм-аут 5 с, ограничение вывода 64 KiB,
protocol_whitelist=file,crypto,data. Сетевые URL и устройства пропускаются.
Кэш проверяет размер/mtime. Удалённые строки ищутся по ID через QPointer,
сырые указатели на удалённые записи не передаются в асинхронные callbacks.

Просмотр папок: дерево файлов с навигацией, выбор файлов/папок, добавление
всей папки без запуска. Ctrl+C/X/V/A в списке, Delete только для записей;
глобальный Ctrl+V вне списка сохраняет прежнее открытие из буфера.
Удаление отсутствующих не удаляет URL/устройства. Открытие папки — файловый
менеджер. Корзина — отдельная команда, подтверждение по умолчанию «Нет»,
перечень путей, удаление успешных файлов из всех вкладок. Нет fallback на
постоянное удаление; неудачные операции сохраняют записи.

Отчёт: настоящий MediaInfo при наличии executable в PATH, иначе явно
обозначенный FFprobe. Чтение асинхронно, 10 с / 1 MiB; закрытие отменяет
процесс. Копирование отчёта. MediaInfo v24.01 проверен из распакованных
пакетов Ubuntu Noble с библиотеками в отдельном каталоге; системные пакеты
не устанавливались. FFprobe fallback проверен штатным PATH без MediaInfo.
