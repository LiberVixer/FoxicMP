GLSL
Ctrl+Alt+V, общие настройки и «Изображение и звук» → «Видео — шейдеры».
Default off. До 16 элементов × 64 КиБ, профиль ≤ 2 МиБ. Имя/галочка/порядок/этап
MAIN либо SCALED. Порядок внутри этапа; все MAIN раньше SCALED. Шаблоны
identity/greyscale/invert/gentle sharpen написаны для проекта. Один vec4 hook(),
HOOKED helpers; без директив/метаданных/compute/произвольных multi-pass файлов.
Checker отдельный процесс, GL3.3 wrapper compile/link, 4sec/entry; во время
валидации пользовательский код не рисуется. Включённая ошибочная цепочка
не закрывает три диалога. Выключенная допускает незавершённый GLSL.
INI на старте проверяется структурно, без повторной компиляции; отложенные
ошибки native pipeline требуют проверки изображения/vo-passes.
OK → INI source + generated Shaders/<SHA256>.glsl. Текущая папка профиля
используется для путей, передаваемых native node-array, без colon splitting.
Cancel не генерирует файлы. Disable/reset снимает список без удаления копий.
Software сохраняет выбор, но GLSL не действует.

Статистика и шаблон
Ctrl+Alt+G, меню Вид/context. Nonmodal window, backend/driver, codec/hwdec,
FPS hints, sync/active, A/V/jitter и drop counters; недоступное «—».
UI render wall time: last/avg/peak по последним 120 вызовам, не физическая
задержка/не FPS видео, GL finish/повторы/grab могут входить в GL время.
Native fresh/redraw passes и nanoseconds→ms только при доступности libmpv.
Reset local samples/native baselines не меняет settings/pause/позицию;
new media resets measurements. JSON → clipboard.
Qt moving vertical line overlay: визуальный compositor test, не native pass.
Видео продолжается, отключение/закрытие диалога удаляет overlay. Screenshot
не доказывает отсутствие tearing. Physical display verification pending.
