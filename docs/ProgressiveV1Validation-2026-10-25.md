# Проверка F-03: каталог сеанса progressive v1

25 октября 2026. [Машиночитаемые результаты и SHA-256](ProgressiveV1Validation-2026-10-25.json).
Это проверка первого этапа [плана интеграции](ProgressiveIntegrationPlan.md),
а не приёмка всей матрицы нового ТЗ.

## Исправления

- Qt и Classic хранят нормализованный каталог внутри объекта источника.
  `update`/`complete` наследуют его; явно переданный другой каталог отклоняется,
  в том числе при абсолютных путях дорожек. Qt больше не игнорирует это поле.
- Новый источник не наследует каталог старого; неудачная замена оставляет старый
  сеанс работоспособным. Обновления Classic после rename проверяют закреплённые
  дескрипторы, а не пытаются повторно открыть прежние имена файлов.
- Classic принимает пустой необязательный `title` от поставляемого клиента.
  Подготовка названия выполняется до закрытия ранее открытого медиа.
- При естественном конце завершённого progressive-сеанса Classic закрывает
  граф и сообщает `finished, active=false`. Для обычных файлов сохранена прежняя
  ветка обработки повторов и действий после просмотра.

Фикстуры — синтетические 20-секундные H.264/AAC файлы из
`qt/tests/generate_media.py`. В каждом варианте подтверждены `playing` при
`complete=false`, несколько update без каталога, отказ на неверный каталог,
rename и последующее `complete` без каталога, `finished, active=false`, отказ
новому сеансу без собственного каталога после завершения и cancel.

Linux использовал частные X11/D-Bus/PulseAudio. Для Classic до первого запуска
записаны `ContextMenuPrompted=1`, `ContextMenuEnabled=0`; discovery не изменил
тестовый INI, снимки HKCU-команд/иконок Classic до/после совпали. Страницы настроек
и системная регистрация не применялись. Одноразовая тестовая задача удалена.

## Установка и границы

Linux EXE обновлён атомарно, прежний сохранён для отката. Версия — `FoxicMPQt
0.2.0` (запрос версии exit 0), идентичность этой сборки задаётся SHA-256 в JSON.
Не изменились 70 остальных установленных файлов, включая INI:
`ac9387b8d09f63317ed8ea3b681abad96e5abe8890400d4db6540017e3acde75`.
Рабочие Windows-установки не заменялись. Опубликованные установщики 0.2.0 не
переупакованы; новый этап относится к текущим исходникам и тестовым сборкам.

Первичные ошибки и их исправления сохранены в JSON, финальный PASS их не скрывает.
При изменении раскладки `CHarvesterSession` требуется пересборка зависимых
статических библиотек; одного `DSUtil` и приложения недостаточно.

Не проверялись вся матрица контейнеров/кодеков, remux, live, несколько дорожек,
длинные пути, 100 циклов, физическая A/V точность и 30-минутный дрейф. Этот regression
подтверждает старт до complete, но не 10 секунд просмотра до complete. Harvester
не менялся и не подключался; общая сквозная совместимость ещё не принята.
