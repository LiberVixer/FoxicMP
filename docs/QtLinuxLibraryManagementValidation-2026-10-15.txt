FoxicMP Qt 0.1.15 — пункт 8: история и избранное
Дата: 2026-10-15. Linux Mint 22.3 x64, Qt 6.4.2, libmpv 0.37.0,
FFmpeg/FFprobe 6.1.1. Xvfb/Mesa llvmpipe. Запрошенный OpenGL фактически
использовал Software fallback. GPU/Wayland не проверялись.

Изменения
---------
Ctrl+H / Недавние файлы → История воспроизведения. Таблица названия,
пути/адреса и позиции, поиск без учёта регистра, категории, выделение
нескольких строк. Открыть выделенные / текущую с начала / копировать
источники (текст и URL MIME) / удалить записи / удалить отсутствующие /
очистить. Enter, Delete, Ctrl+C действуют внутри списка. Недоступные локальные
файлы отмечены цветом. Сетевые адреса и физические устройства не проверяются
на наличие; DVD/Blu-ray образы/папки проверяются как локальные пути.
Удаление касается только записей/позиций, не медиафайлов или избранного.
Удалённая текущая позиция не восстанавливается фоновым таймером или открытием
меню. Повторное открытие источника разрешает запись заново.

history/limit: 1–10000, по умолчанию 50; history/menuLimit: 0–100, по умолчанию
50; 0 скрывает только записи меню, оставляя окно истории доступным.
MRU без дубликатов, только успешные открытия. Уменьшение лимита сокращает
список, но не стирает позиции вне списка; явное удаление/очистка стирает их.
Запись истории и автоматическое продолжение отключаются независимо, как раньше.

Избранное: поиск, категории, копирование, удаление, редактирование названия,
позиции и типа пути. Кнопки ↑/↓ и внутреннее перетаскивание. При фильтре
перетаскивание отключено; кнопки меняют только порядок видимых элементов в
их прежних глобальных местах, скрытые остаются на местах. После перестановки
сохраняются выделение и текущая строка, редактирование продолжает работать.
Cancel редактора/добавления не меняет запись; пустое название запрещено.

Для каждой записи rememberPosition: true открывает её собственную позицию,
независимо от автоматического продолжения; false явно открывает с нуля.
Относительный путь доступен файлам и образам/папкам DVD/Blu-ray; при переносе
надо сохранить взаимное расположение папок программы и медиа. Для дисков
переносится только path в структурированном URI; заголовок/угол сохраняются.
Сеть и прямые/физические устройства не преобразуются в относительные пути.
У прямых/физических входов позиция недоступна. Добавление такого источника
не сбрасывает общий выбор сохранения позиции/относительного пути для новых
файлов. DVD/Blu-ray/Audio CD и устройства/ТВ имеют фильтры и подменю.
Обычные файловые закладки доступны непосредственно в меню избранного.

Новая вкладка «История и избранное»: лимиты и начальные параметры новых
закладок. Cancel параметров не применяет значения. Старый JSON избранного
читается с rememberPosition=true и portable=false, без потери названий,
порядка и позиции. Все данные — FoxicMPQt.ini рядом с программой.

операция модели, которую выполняет внутреннее перетаскивание QListWidget.

При предварительной проверке найдена потеря текущей строки после перестановки;
исправлено восстановление курсора/выделения. Завершение модальных окон
отсоединяет обработчики с захватом локальных ссылок перед уничтожением
дочерних виджетов. При чтении кода найден сброс общего выбора позиции при
добавлении прямого входа; исправлен и покрыт отдельным UI-сценарием.
После последнего изменения все 10 наборов повторены в обоих режимах.
clang-format --dry-run --Werror: чисто для изменённых C++ модулей.

Два режима имеют разные Xvfb/каталоги/скриншоты. Устройства используют
собственные виртуальные PulseAudio monitors; модули выгружены, личный микрофон
не используется. Настройки установленной копии и Classic Windows не менялись.
Интерфейс Harvester остаётся отключённым. Коммит/push/release не выполнялись.
