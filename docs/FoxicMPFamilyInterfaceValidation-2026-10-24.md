# FoxicMP: единая структура меню и настроек

Проверка этапа F3, 24 октября 2026 года. Эталон — текущая Linux Qt.

## Linux Qt и Windows Qt

Обе Qt-сборки используют общий `organizedmenus.cpp` и `classicpreferences.cpp`:
верхнее и контекстное меню строятся из одних действий; окно настроек содержит
дерево слева, вкладки справа, поиск и индикатор загрузки. Общие действия,
профили и сохранённые пользовательские значения проверены в Windows Qt native
suite: 21/21 PASS.

## Windows Classic

`CPPageSheet` сохранён на базе MFC TreePropSheet, но страницы теперь получают
иерархические пути Linux Qt-образца:

- General;
- Interface and window;
- Control;
- Playback;
- Video;
- Audio;
- Subtitles;
- Capture and devices;
- Online and network;
- Service.

В окне настроек добавлены поле поиска страниц и строка результата. Поиск
раскрывает подходящую категорию и выбирает найденную страницу; пустой запрос
возвращает подсказку. При создании окна показываются текст и marquee-индикатор
«Loading settings...», затем элементы управления включаются сообщением GUI.
Существующие страницы, обработчики Apply/Cancel и формат профиля сохранены.

Главное меню Classic пересобирается после загрузки ресурса в девять разделов:
File, Playback, Video, Audio, Subtitles, Library, View, Service, Help.
Существующие File/Playback/View/Help-подменю сохраняются; специализированные
команды Video/Audio/Subtitles/Service размещены в новых разделах. IPC, numeric
command IDs, контекстные меню, профили и настройки пользователя не меняются.

## Проверка

- Windows Classic Release x64 собран через MSBuild после изменений дерева,
  поиска и меню.
- Изолированный запуск Classic с новым и пользовательским INI завершён кодом
  0; defaults, громкость, OSD, seek distances и пользовательская команда
  сохранились согласно предыдущему семейному тесту.
- Windows Qt: 21/21 PASS после общей семейной проверки.
- Linux Qt: `classic-interface`, `playback-controls`, `input-control`,
  `profile-archives` — 4/4 PASS; Linux Qt остаётся эталоном.
- Рабочие Windows/Linux профили не менялись. Временные Scheduled Tasks
  проверки удалены.

Ограничения сохраняются: системные названия новых Classic-разделов сейчас
используют английские подписи ресурса; переводимые страницы и содержимое
диалогов остаются локализованными штатными ресурсами Classic. Это можно вынести
в следующий ресурсный перевод без изменения структуры и команд.
