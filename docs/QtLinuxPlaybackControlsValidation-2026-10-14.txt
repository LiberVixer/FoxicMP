Реализация и поведение
=====================
Вкладка «Воспроизведение», главное и контекстное меню, редактируемые клавиши.
Шаги перемотки: 1000/5000/20000 мс по умолчанию, настраиваются 1–600000 мс.
Shift+стрелки / стрелки / Ctrl+Alt+стрелки; Home — в начало.
Точная перемотка либо режим ключевых кадров для обычного источника.
Alt+стрелки — относительный направленный seek по ключевым кадрам;
на контролируемом GOP=1 секунда проверены переходы 4,4 → 5 → 4.
Для progressive шаги всегда точные, отдельные ключевые кадры отключены.
Прямые входы не перематываются.

A–B: клавиши [ / ], Backspace, диалог Ctrl+Shift+B с точностью 1 мс.
Минимальный отрезок 50 мс. Временные точки отмечены на таймлайне;
не сохраняются в профиль, очищаются при смене файла, Stop/Close/EOF.
0 проходов — бесконечно; N включает первый проход, движку задаются N−1
переходов к A. После конечного числа проходов просмотр продолжается за B.
Прогрессивный отрезок требует единого подтверждённого диапазона кэша;
при потере диапазона/соединения повтор очищается. В движок передаются
координаты с timestampOffset, в интерфейсе используются времена фильма.

Повтор файла или всего списка: 0 — без ограничения, N — всего проходов.
Случайный порядок учитывает каждый файл в каждом полном проходе; исправлен
пропуск последнего файла предыдущего прохода при запуске следующего.
Ручной выбор и смена режима сбрасывают счётчики; автоматические переходы
сохраняют счётчик проходов списка. Явное действие после окончания сохраняет
приоритет до повторения, как в пункте 5. Ручной Stop/ошибка его не запускают.
Возврат к началу после последнего прохода открывает последний файл на паузе
с нулевой позиции, если не выполнено другое явное действие.

Скорость: Ctrl+Up/Down, Ctrl+R (1×), меню фиксированных значений.
Авто: 0,125/0,25/0,5/1/1,2/1,5/2/4/8/16×, как положительный ряд Classic.
Процентная сетка: 1/5/10/20/25/50/100%. Скорость при смене файла сбрасывается,
либо сохраняется на текущую сессию по настройке. Повтор того же файла
сохраняет скорость. Новый процесс начинает с 1×; скорость не пишется в INI.
Для прямых входов изменение скорости отключено.

Пауза при сворачивании выключена по умолчанию, действует только на выбранную
видеодорожку. Восстановление возобновляет только собственную автоматическую
паузу. Ручная пауза, кадровый шаг и буферизация имеют отдельное состояние;
аудиофайл при сворачивании продолжает играть. Progressive учитывает
автоматическую паузу вместе с общей паузой видео/аудио и состоянием загрузки.

Проверка
========
PlaybackControlTest проверяет отмену/применение и сохранение настроек,
реальные перемотки и ключевые кадры, скорости и новую сессию, конечный A–B,
диалог отрезка, повтор файла/списка/shuffle, возврат к началу, сворачивание
видео/ручную паузу и продолжение аудиофайла. Использованы обычные локальные
файлы с декодированием libmpv; естественный конец достигается перемоткой
к концу, а не подменой сигнала EOF.

Конечный A–B подтверждается фактическими обратными переходами time-pos
и последующим выходом за B: для 3 проходов два возврата к A.
У libmpv 0.37 нет свойства remaining-ab-loops. Тест не принимает отсутствие
свойства за нулевой счётчик; он проверяет абстракцию через реальное движение.
Поддерживаемый ab-loop-count и поведение сверены с исходником mpv 0.37.

В ProgressiveTest дополнительно проверяются A–B в кэше (один возврат для
двух проходов), отказ от незагруженной B, отключение ключевых кадров,
автоматическая пауза при сворачивании, сохранение ручной паузы после
пополнения буфера. Варианты: fMP4, fast-start MP4, длительность из индекса.
Отключённый интерфейс Harvester сохранён.

Все профили проверок временные; установленный Windows-профиль не изменён.
OpenGL на физическом GPU, Wayland, аналоговое ТВ, меню дисков и физические
устройства не подтверждаются этим протоколом; задачи пункта 3 отложены
пользователем. Непрерывный soak остаётся отдельным опциональным тестом.

Реальный снимок окна настроек: docs/images/foxicmp-qt-playback-controls.png.
Сборка Release, clang-format и запуск пакета проверяются перед выдачей.
Основания API и сравнения:
https://mpv.io/manual/stable/#list-of-input-commands
https://raw.githubusercontent.com/mpv-player/mpv/v0.37.0/player/playloop.c
src/apps/mplayerc/RateControl.cpp; AppSettings.h; PPagePlayback.cpp; MainFrm.cpp.
