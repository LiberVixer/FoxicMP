FoxicMP Qt 0.1.62 — organized menu validation, 2026-10-22

The menu bar and video context menu now share nine functional sections:
File, Playback, Video, Audio, Subtitles, Library, View, Tools and Help.
The same QMenu/QAction objects are reused, so shortcuts, checkmarks, enabled
states and dynamic track/history entries stay synchronized. The hierarchy is
unchanged when the main menu is hidden or the player enters fullscreen.

File contains sources, recent files, reopen/close, media copy and properties.
Playback contains seek, chapters, frame stepping, speed, repeat/A–B and the
after-playback action. Video contains video track, aspect/fitting, zoom,
position/crop, rotation/mirroring, color/ICC, shaders, stereo and video output.
Audio contains tracks, external audio, volume, delay, output device and audio
processing. Subtitles contains tracks, visibility, loading, delay, cue stepping,
style, editor and reload. Library contains playlist operations, history and
favorites. View contains fullscreen, window size, panels and window modes.
Tools contains captures, web control, profiles, associations and diagnostics.
Help contains shortcuts, command-line help, updates, project page and About.

The former catch-all “Дополнительно” menu was removed. Classic commands that
have no Linux implementation are omitted instead of occupying disabled empty
placeholders. The old Classic resource remains the source of command captions,
IDs and aliases; the user-approved Linux grouping controls placement.
