Дата: 2026-10-15. Linux Mint 22.3 x64, Qt 6.4.2, libmpv 0.37.0,

Реализация и совместимость
-------------------------
PlaylistFile::readEntries/writeEntries: источник, название, длительность,
метаданные дорожек и глав. Импорт M3U/M3U8, MPCPL, PLS, ASX и CUE;
экспорт M3U/M3U8, MPCPL, PLS и ASX. QFile/QSaveFile, ограничение 4 MiB /
10000 записей. Ошибка импорта не заменяет очередь/текущий файл. Ошибка
экспорта не затирает уже сохранённый файл. Вложенные плейлисты не раскрываются
парсером; добавление нескольких локальных списков в панель атомарно.

UTF-8, UTF-16 LE/BE с BOM; невалидный UTF-8 в старых форматах пробуется как
Windows-1251. M3U8 строго UTF-8. Относительные пути разрешаются рядом со
списком; обратные слеши Windows принимаются для относительных путей.
Абсолютные drive/UNC-пути надо сопоставить Linux, DirectShow device-типы
не превращаются в Linux-устройства. Проверен реальный native MPCPL Classic
с повторными filename (внешнее аудио), subtitle, label с запятой и time.
Экспорт time использует hh:mm:ss, совместимый со StringToReftime2 Classic.
Дробная длительность сохраняется в дополнительной записи FoxicMP.

PLS: FileN/TitleN/LengthN/NumberOfEntries, числовой порядок. ASX:
ENTRY/REF/TITLE/DURATION, регистр тегов/атрибутов независим; XML DTD запрещён,
повреждённый XML отклоняется. Первый REF в ENTRY; альтернативные REF, внешние
ENTRYREF и скрипты не разворачиваются. Относительные URI в ASX кодируются
и декодируются с сохранением пробелов, #, %, русских символов.

CUE: локальные FILE и AUDIO TRACK, TITLE/PERFORMER, INDEX 01; INDEX 00
не является началом главы. Минуты/секунды/кадры, кадры <75, секунды <60,
строго возрастающие времена на файл. Один элемент очереди на файл, свои
главы у каждого файла. Проверен переход на 00:02:37: ожидалось 2.493333 с,
mpv сообщил 2.493 с. Это проверка времени команды, не физической A/V-точности.
Меню глав и Ctrl+PgUp/PgDown используют seek к времени главы; экспорт
и переносимый профиль сохраняют главы. CUE не экспортируется, вместо этого
выбирается обычный плейлист с дополнительными данными FoxicMP. Смешанные
BIN data/audio не декодируются как CDDA; проверены обычные локальные медиа.

Дорожки и ошибки
----------------
Выбор aid/sid привязан к стабильному UUID строки: дубликаты одного файла
независимы. Файловые mpv-options сбрасывают выбор на auto для новой строки;
после добавления внешних дорожек ожидаемые ID применяются по наличию.
Выбранная внешняя дорожка также определяется по external-filename, поскольку
асинхронная загрузка может менять её числовой ID. Проверены два внешних аудио,
смена на второе, повторное открытие и сохранение именно выбранного файла.
MPCPL пишет внешние файлы в стандартные filename/subtitle. Остальные данные —
необязательные поля/комментарии FoxicMP в MPCPL/PLS/ASX/M3U; другие плееры
сохраняют обычные записи, но могут игнорировать эти расширения.

playlist/advanceOnError (false): переход только после ошибки основного файла,
не после произвольной ошибки команды. Генерация отменяет отложенный переход
после ручного Stop/смены записи/закрытия. Один обход повреждённых записей,
в том числе repeatAll и shuffle; успешная загрузка начинает новый обход.
Ошибки не выполняют действия после просмотра.
playlist/skipInvalid (true): пропуск уже ошибочных строк при Next/Previous,
shuffle и определении конца прохода. Прямое выделение/Enter повторяет попытку;
успех снимает отметку. Цвет и ошибка видны в строке/подсказке. Отметки не
пишутся в профиль: после перезапуска файл можно проверить заново.
playlist/skipInvalidSources (false): отдельный пропуск неподдерживаемых
адресов/типов при импорте; повреждённая структура всё равно отменяет импорт.

Панель и параметры
------------------
Вкладка «Плейлист»: три настройки ошибок/импорта, фоновая длительность,
скрытие в полном экране, дорожки, размещение панели. Cancel не применяет
изменения. Отключение фонового определения отменяет probe; повторное
включение определяет неизвестные локальные длительности. URL/устройства
автоматически не опрашиваются. Размещение слева/справа/сверху/снизу/отдельно;
QMainWindow state и floating geometry сохраняются рядом с программой,
включая видимость. Полный экран восстанавливает прежнюю видимость панели.
Профили Windows и установленная пользовательская копия не менялись.
Harvester GUI остаётся отключённым.
