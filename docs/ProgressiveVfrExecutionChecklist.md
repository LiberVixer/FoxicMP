# VFR: рабочие подпункты и правила подсчёта

База оставшегося плана: **77 составных требований** из
[основного чеклиста](ProgressiveCompletionChecklist.md). Исторические 149
подтверждённых записей включают результаты отдельных профилей и проверок;
они не являются закрытием 149 требований того же размера.

С 15 ноября 2026 счётчики разделены:

- Большое требование закрывается только после выполнения всего его объёма.
- Новое доказательство записывается ссылкой или примечанием, без нового
  выполненного checkbox в основном списке.
- Для этапа заранее фиксируются подпункты. Завершение меняет `[ ]` на `[x]`,
  поэтому число оставшихся подпунктов уменьшается при неизменном общем числе.
- Новые необходимые подпункты добавляются с объяснением изменения объёма.
- Счётчики показываются только в итоговом ответе по заданию.

## Текущий этап: progressive WebM VP9/Opus VFR

Всего **14** подпунктов. Состояния «реализовано», «первичный прогон» и
«финальная проверка» ниже намеренно названы отдельно: успешный ранний прогон
не заменяет проверку окончательного бинарника.

- [x] VFR-01. Реализовать отдельный режим и неизменяемые videoSamples/audioSamples.
- [x] VFR-02. Реализовать структурную обработку finite/unknown Clusters, проверку BlockDuration, PTS, endpoints и references.
- [x] VFR-03. Реализовать разрешение отсутствующего DefaultDuration только для явно выбранного VFR-пути.
- [x] VFR-04. Подключить проверку фактических интервалов к кэшу и состоянию готовности.
- [x] VFR-05. Подключить SDK/capabilities и проверить типы, идентичность и совместимость модулей: 53 + 19 + 63 unit tests.
- [x] VFR-06. Реализовать передачу VFR-флага в повторный FragmentIndex Classic; финальный функциональный прогон учитывается отдельно.
- [x] VFR-07. Выполнить первичный Linux Qt прогон: 6 ordinary-main сценариев и 6 PCM captures, с отдельными профилями.
- [x] VFR-08. Выполнить первичный Windows Qt ordinary-main прогон: 6 сценариев.
- [x] VFR-09. Проверить окончательный ordinary-main VFR-профиль всех трёх редакций, включая исправленный Classic.
- [x] VFR-10. Проверить PCM окончательных Qt/Classic сборок во всех трёх редакциях.
- [x] VFR-11. Завершить финальные worker/fault/negative проверки, sanitizer gates и прежние CFR/NTSC/25fps/AAC регрессии.
- [x] VFR-12. Свести результаты трёх редакций, точные exits, SHA и контроль сохранности установок/регистрации.
- [x] VFR-13. Атомарно обновить установленный Linux с backup и неизменным профилем; проверить его собственный SDK.
- [x] VFR-14. Обновить инструкции/матрицу, проверить чистый SDK, сохранить commit и push.

Промежуточные доказательства находятся в `_bin/webm-vfr-*`. В частности,
окончательный Linux worker прошёл **36/36** сценариев (exit 0), а
ASan/UBSan — **4000/4000** mutations. Это части VFR-11, который не закрывается
до завершения остальных перечисленных в нём проверок на трёх стендах.

Первый Classic VFR-прогон выявил отказ без DefaultDuration. Исправление
в HarvesterSession/FragmentIndex прошло финальный ordinary-main прогон
6 профилей Classic. Во всех трёх редакциях проверены по 6 ordinary-main cases
и 6 PCM captures; результаты раздельно сохранены в `_bin/webm-vfr-final2-*`.
YouTubeHarvester не изменялся.

Ранее штатная песочница не разрешала создание частного D-Bus (exit 127 до
запуска плеера), а проверка разрешений была недоступна. Доступ к разрешённым
изолированным стендам восстановлен; повторные функциональные прогоны прошли.
Исходный инфраструктурный отказ сохранён отдельно, он не считается PASS.
