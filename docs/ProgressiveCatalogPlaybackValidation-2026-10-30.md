# Проверка playback каталога — 30 октября 2026

SDK 1.37, capability `segmentedPlayback.catalog.mode=paged-fmp4-v1`.
[Контракт и ограничения](ProgressiveCatalogPlayback.md),
[машинный отчёт](ProgressiveCatalogPlaybackValidation-2026-10-30.json).

| Профиль, 90 секунд | Linux Qt | Windows Qt | Windows Classic |
|---|---|---|---|
| H.264 + AAC mono, 182 ресурса | PASS | PASS | PASS |
| HEVC Main10 + Opus stereo, 183 ресурса | PASS | PASS | PASS |
| AV1 Main10 + AAC mono, 182 ресурса | PASS | PASS | PASS |

Все девять сценариев начинают просмотр недокачанного источника, сохраняют
пользовательскую паузу при update, перематывают вперёд к 35 с, назад к 2 с,
потом к 68 с после роста каталога свыше 128 ресурсов. Проверяются пропавшая
новая страница/retry без изменения принятой revision, complete, seek к 87 с,
естественный EOF, release и новый reader при повторном открытии полного каталога.
Главный reader ID остаётся одним во время pause/update/seek первого просмотра.

Обе Qt-сборки проверяют меняющиеся кадры в начале и после перемоток, фактические
codec/pixelformat (`h264`, `hevc`, `av1`; 10-bit для последних двух), audio decoder,
48000 Гц и mono/stereo. Classic использует реальные DirectShow-графы; целевые
позиции выбираются через опубликованные главы. Сравнение пикселей и физических
аудиовыходов Classic этим сценарием не выполнено.

## Дополнительные проверки

- 22 одинаковых native bridge-сценария на каждой ОС: полностью совпадающие
  виртуальные байты всех 15 прежних сочетаний кодеков, рост страниц, старые
  offsets, отсутствие I/O в metadata preflight, ошибки/повтор страниц,
  обязательный SHA, неизменность режима и последний владелец.
- На обеих ОС прошли 295 прежних segment-stream и 468 обычных media-проверок,
  модель/сегменты, integrity, staging, диагностические native/API сценарии.
- Модель каталога — 51 случай на ОС; файловые страницы — 25 Linux/24 Windows;
  bounded cache/leases — 15 на ОС. Это разные уровни проверки, не дополнительные
  декодированные клипы на 8192 файла.
- Qt compatibility: v1 writer, scalar VP9 10-bit/Opus и два прежних inline
  segmented-профиля; QTest 6 результатов с init/cleanup на каждой ОС, exit 0.
- SDK-клиент — 23 unit tests; family contract — 2; Classic v1 directory contract
  повторён в отдельном тестовом EXE, exit 0.

Первый Linux playback-прогон вернул exit 8: тест ожидал paused на 68 с при
доступных 72 с, а штатному resume buffer требовалось больше данных. Все три
профиля корректно оставались buffering. После публикации до 80 с повтор прошёл,
QTest 5/5 с init/cleanup. Плеер ради этого теста не изменялся.

Общий Linux native/diagnostic прогон: 12/13 групп, exit 8. Qt diagnostic не получил
`FOXICMP_TEST_MEDIA`, завершился в init до открытия окна; повтор через частные
X11/D-Bus/PulseAudio и правильные fixtures — exit 0. Windows: 13/13 групп, exit 0.
Все Linux playback/audio прогоны выполнялись через `qt/tests/run_tests.sh`;
неудачный init диагностики отражён отдельно, его нельзя считать успешным прогоном.

## Установка и границы результата

Linux EXE заменён атомарно после проверок. Предыдущий EXE сохранён для отката;
INI SHA до/после совпал, проверены 195 прежних личных файлов. Версия и capability
сверены на установленном EXE через отдельный профиль. Запущенного установленного
плеера перед заменой не было; просмотр не останавливался.

Windows-приложения проверялись в build/private-копиях. Classic INI до первого
запуска содержал `ContextMenuPrompted=1`, `ContextMenuEnabled=0`; harness сверил
HKCU-команды/иконки установленного Classic до/после. Его одноразовая задача
завершилась с LastTaskResult 0, EXE SHA совпал со сборкой; task и stage удалены.
Установленные Windows EXE/профили, MPC/MPC-BE, MPMY и Harvester не менялись.

Не проверены многочасовой просмотр, декодирование 8192 реальных медиафайлов,
медленные/зависшие диски, физический A/V offset/drift, Wayland или оборудование.
Полностью готовый большой каталог пока индексирует подтверждённый префикс
при подготовке и может превысить deadline; ленивый backend-индекс ещё нужен.
SDK 1.37 не завершает всё расширенное ТЗ: WebM/TS-сегменты, muxed A/V,
смена конфигурации/live и реальные источники остаются по плану.
