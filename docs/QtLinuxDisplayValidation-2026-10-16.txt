ICC
Ctrl+Alt+V, общие настройки, «Изображение и звук»: две новые страницы.
Default ICC off. RGB display profile ≤16 МиБ; заголовок/размер/signature и
cmsOpenProfileFromMemTHR + sRGB→profile transform в приватном LCMS-контексте.
OK импортирует bytes в ColorProfiles/<SHA256>.icc через QSaveFile, относительный
путь в INI. Dedup, перенос папки и точные bytes проверены. Cancel не создаёт
копию. Ошибки в трёх диалогах оставляют окно открытым. Reset не удаляет файлы.
Все четыре rendering intent проверены. ICC option и путь приняты libmpv.
icc-cache=false, icc-profile-auto=false — нет системного LUT-cache или OS lookup.
Применение ICC только OpenGL; Software, preview и native video screenshot
не преобразуются в профиль монитора. Неверный ICC из INI пропускается со статусом.
Профиль ОС/привязка разных мониторов пока не реализованы.

Синхронизация
Default audio; display-resample/display-tempo/display-vdrop optional.
VSync фактически задаётся QSurfaceFormat, interval 1 или 0 и согласованный native
mpv option. Сохранённый выбор требует restart. Подсказка частоты QScreen либо
manual 1–1000Hz (0=Qt). Max video change 0–5% default1; extra audio change
0–1% default0.125. Interpolation defaultoff; temporal native/oversample/linear/
mitchell. Default tscale captured/restored.
Policy display-* требует visible+ready OpenGL, reported/requested Qt interval1,
finite refresh>0, permitted bitstream=false. Иначе временно audio, interpolation
off, override0; выбор INI сохранён. Перепроверка раз в секунду. Frame polling
16ms audio, 1–16ms display по refresh, без блокирующего ожидания на UI.
Статус показывает native video-sync, display-sync-active, hint/estimated FPS,
avsync, frame drops. Частота Qt и requested interval не доказывают физический
VBlank; драйвер/композитор может переопределять VSync. Monitor modes/HDR не меняются.
