Буфер: MIME URL и построчный текст, Unicode, неверные/пустые/большие списки,
неизменность выходного списка при ошибке; реальный второй процесс передаёт

Веб-порт: сохранённый порт занят при создании окна, но начальный временный
порт включается без попытки открыть сохранённый. Изменение порта в живом
окне отражается в открытом диалоге. Повтор порта сохраняет объект/токен;
занятый новый порт сохраняет сервер, токен, громкость и не открывает файл.
Новый настоящий процесс отвечает HTTP на временном порту, завершён через
MPRIS Quit с кодом 0; следующий запуск использует сохранённый порт.
Проверки HTTP Host/Origin/кода доступа из WebControlTest также пройдены.

Сброс: только временные тестовые профили. JSON результата, точная копия INI,
включая старый файл без версии/с комментарием, сохранение библиотеки по умолчанию,
явная очистка, сохранение журнала отката интеграции. Отказ при живом владельце
и каноническом alias, отсутствии папки/INI, ссылке/FIFO, повреждении INI и
невозможности создать Backups. В отдельной копии программы проверен portable
с FIFO вместо стартового INI и недоступным внешним языковым файлом.
GUI-сброс, экспорт/импорт и защита новых писателей проверены ProfileArchiveTest.
Обычные desktop/profile-launch и maintenance проверки также включены.
