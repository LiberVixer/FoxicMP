Функции
Ctrl+Alt+I — немодальные свойства текущего источника. Основное/дорожки/JSON/
MediaInfo-FFprobe. Native snapshot, explicit Refresh; JSON и внешний отчёт
копируются отдельно. Разрешение/FPS, container/size/duration, codecs/bitrates,
audio sample rate/channels, tags/chapters/cache. Неизвестное не подменяется.
External report — только по кнопке для локального файла, MediaInfo либо FFprobe,
10 секунд и 1 МиБ. Закрытие завершает worker. Сетевой источник через libmpv.

Ctrl+S — снимок с диалогом, F12 — без диалога, Alt+C — кадр в clipboard.
Отдельная команда Qt displayed video-area со scale/полями/OSD. Настройки:
PNG/JPEG/BMP/WebP при наличии Qt writer, качество1–100 default90; субтитрыtrue.
Defaults PNG; выбранные параметры сохраняются в соседнем INI. Cancel/reset.
Native screenshot-raw async, ограниченная копия bgr0 positive stride <=33554432
пикселей до освобождения mpv_event_command. Не более4 pending captures.
QImageWriter/QSaveFile, атомарный вывод. Промежуточный PNG не создаётся.
Старый public saveFrame сохранён, регрессии API прошли.
Снимок кадра не равен физическому цвету композитора/ICC/HDR экрана.
Qt widget grab отображаемой области включает OSD и поддержанные Qt children.

Лист миниатюр: FFmpeg через изолированный FramePreview decoder, selected
internal ff-index (явный -map), local file, известная длительность<=7 суток.
Grid1–6×1–10, width80–480; defaults4×4/240. Равномерные точки внутри duration,
letterbox и timestamp. Player seek/pause не меняются. Без player filters/subtitles/
ICC/shaders. Progress/cancel; один активный лист. Decode timeout3,5s/frame.

Копия: local completed file без перекодирования; 1MiB per Qt timer tick,
progress/cancel, QSaveFile сохраняет прежний target при отмене/ошибке.
Проверяются размер и mtime источника; замена исходного файла запрещена.
Один copy job. Сетевые/устройства/диски/incomplete-progressive не копируются.
Одна файловая операция на медленной ФС может задержать UI.
