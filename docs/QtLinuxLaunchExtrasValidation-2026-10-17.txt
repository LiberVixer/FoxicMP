FoxicMP Qt 0.1.43 — дополнительные команды запуска
Дата: 17 октября 2026; Linux Mint 22.3 x64; Qt 6.4.2 / libmpv.

Полная Release-сборка всех тестовых программ завершена без ошибок.
Software: 34/34 групп CTest PASS, 580.74 с.
OpenGL (затронутые группы): 14/14 PASS, 326.36 с.
LaunchOptionsTest: 10 PASS, 0 FAIL, 0 SKIP в каждом режиме.
Xvfb, отдельные D-Bus-шины и PulseAudio null sink; Mesa/software fallback.
Физические GPU/мониторы/аудиоустройства и Wayland не подтверждены.
Необязательный continuous soak не включался.

Новые проверки: JSON списка мониторов/аудиоустройств без создания профиля;
сочетания запросов и управляющих ключей; границы/типы/известные действия.
Выбор экрана по номеру/primary, fullscreen/normal, временная цель экрана.
Сохранённый пресет с русским именем, встроенный fit, изменение масштаба видео,
обычные правила сохранения преобразований, shuffle/no-shuffle и audio-device.
Конкретный выход PulseAudio null sink выбран реальным вторым процессом.
Отсутствующий экран/устройство/пресет отклоняются до изменений очереди,
громкости и сохранённых преобразований; появляется диагностическая причина.

Однократность: --after none подавляет сохранённое close на один проход,
следующий проход снова закрывает файл. --after shutdown переживает Stop,
вызывается один раз и затем возвращается сохранённое правило close.
Системный исполнитель в тесте подменён; компьютер не выключался.
Старые after-playback/transform/audio-routing/input/window/profile проверки
включены в итоговые прогоны.

Первая фокусная проверка ожидала точный double 1.3, libmpv возвращает
float32 1.29999995232. Для масштаба принят допуск 0.0001; исходный лог
сохранён в _bin/qt-cli-043-focus-first.log. Код плеера из-за этого не менялся.
В первом тесте пакета shuffle уже был выключен по умолчанию; отсутствие
записанного false не является ошибкой. Тестовый профиль теперь начинается
с shuffle=true, прежняя проверка false подтверждает реальное переключение.
Тот же архив прошёл повтор; код плеера и условия проверок не менялись.
Исходный лог: _bin/qt-package-043-check-first.log.

Первый полный Software-прогон прерван перезагрузкой компьютера на группе
desktop-integration, поэтому не считается завершённым. Журнал сохранён:
_bin/qt-ctest-0.1.43-software-first-incomplete.log. В нём был сбой пиксельной
проверки stereo Auto; он воспроизвёлся отдельно. Диагностические запуски
изменили тайминг и прошли четыре раза. Тест останавливал декодирование через
фиксированные 100 мс после смены фильтра. Теперь он ожидает нужный кадр по
тем же пикселям и дополнительно проверяет их после паузы; критерии цвета
и размера сохранены. Временная диагностика удалена. Исправленная группа
TransformTest прошла четыре последовательных запуска (7 PASS в каждом),
затем свежие итоговые Software/OpenGL прогоны. Код обработки видео не менялся.
Повторы: _bin/qt-ctest-0.1.43-transform-final-software.log.
