режимах. Чужие Origin, null Origin и подменённый Host отклоняются. Ограничены
размер/время запроса и число клиентов; Stop закрывает недочитанные подключения.
Команды ограничены прежним allowlist; чтения файлов/произвольных команд нет.

С Windows 192.168.11.1 через предоставленный SSH запущен HTTP-клиент PowerShell
к тестовому серверу на Linux 192.168.11.111. Страница 200, правильный Bearer 200,
пауза и громкость 42 подтверждены по состоянию реального тестового Player.

не менялись. Сервер Windows-проверки — отдельный тестовый Player с временным
профилем, теми же UI/core и изолированным аудиовыходом, а не упакованный exe.

Отдельно сам упакованный stripped exe запускается с временным сохранённым LAN-
профилем: страница на частном IP доступна, loopback закрыт, API без/с неверным
кодом 403. После перезапуска с --web-port доступен только loopback, LAN закрыт,
сохранённые LAN/IP/порт прежние. Старые package smoke и тесты stdin/CLI PASS;
WebControlTest повторён как связанный UI/core-тест при проверке пакета.

HTTP не шифруется, только доверенная LAN. IPv4 RFC1918 и 169.254/16; IPv6,
публичные IP, wildcard, TLS, открытие портов брандмауэра/роутера не добавлены.
При изменении DHCP нужно обновить список и применить новый адрес вручную.
Xvfb/Mesa не заменяет физический GPU/Wayland; continuous soak не включён.
