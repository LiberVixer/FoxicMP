# Проверка воспроизведения сегментов — 30 октября 2026

SDK 1.33, профиль `segmented-fmp4-h264-aac-lc`. Проверены реальные декодеры
в Linux Qt, Windows Qt и Classic; Harvester и установленные Windows-приложения
не менялись. Это ограниченный fMP4 VOD профиль, не произвольный HLS/DASH backend.

| Сценарий | Linux Qt | Windows Qt | Classic |
|---|---|---|---|
| Пропуск media-сегмента скрывает последующие готовые ресурсы | PASS | PASS | PASS |
| После заполнения пропуска играют ещё недокачанные A/V | PASS | PASS | PASS |
| Пауза сохраняется при публикации новых сегментов | PASS | PASS | PASS |
| Перемотка к 2 с на паузе и возобновление | PASS | PASS | PASS |
| На недокачанном хвосте buffering вместо EOF | PASS | PASS | PASS |
| Complete и естественный EOF с освобождением всех readers | PASS | PASS | PASS |

В обеих Qt-редакциях дополнительно проверены AAC 48000 Гц и меняющиеся
декодированные видеокадры. Это не измерение физического звукового выхода.
Во всех трёх редакциях сохраняется один readerId на весь сценарий.

Native stream: 14/14 на каждой ОС: границы байтов, префикс, позднее добавление
ресурсов/сегментов после init-only, запрет встроенного нового init и media в init,
недопустимые конфигурации/offset/sequence, SHA-256, усечение, отмена и последний
внутренний владелец. Отдельная диагностика одного сегмента — 18 native случаев
на каждой ОС и 12 IPC случаев в каждой редакции. Media regression — 468/468
на каждой ОС. Итог Linux CTest regression 9/9, Windows 10/10; все exit 0.
Прежние v1 writer, scalar fMP4 H.264 и partial optional AAC прошли на обеих
Qt-редакциях: 5 результатов с init/cleanup, exit 0. Classic v1 sessionDirectory
контракт также прошёл. Python SDK 15/15, family contract 2/2, exit 0.

Первый Linux playback прогон завершился exit 8: lavf сканировал недокачанный
хвост. Исправлен режим byte seek/ignidx и чтение по потребности, повтор exit 0.
Первый Windows build — exit 1 из-за макроса `near`; имя заменено. Отдельный
повтор build — exit 1 из-за пересечения Ninja build-процессов; последующие
сборки выполнены последовательно, exit 0. Первый Classic прогон — exit 1:
в тестовом PATH отсутствовал ffprobe; исправлен PATH, повтор exit 0.
При разработке native теста исправлены длительность последнего AAC sample
(явный trun вместо значения ffprobe), пагинация readers и ожидаемый код ошибки.
Финальные результаты и точные exit codes сохранены в JSON.

## Установка и очистка

Проверенная Linux-сборка атомарно установлена в `_bin/FoxicMPQt-linux-x64`.
Сохранены INI и все 191 ранее существовавший личный/служебный файл. SHA-256
INI до и после: `ee2a51243880e578a7b1f38a0278ed178d1e2e379ba0f4f756b5f77427ac24b6`.
Резервная копия: `foxicmp-qt.before-sdk-1.33-20261030T042110Z`.
Версия приложения остаётся 0.2.0; возможность определяется capability профиля.

Classic запущен отдельной тестовой копией с отключённой регистрацией контекстного
меню; harness сравнил HKCU commands/icons до и после. Одноразовая задача и
тестовый каталог удалены, LastTaskResult=0; hash проверенного EXE совпал со сборкой.
Системный микшер, пользовательские профили Windows, Harvester, Wayland и физическое
оборудование не менялись и не использовались в этих испытаниях.
