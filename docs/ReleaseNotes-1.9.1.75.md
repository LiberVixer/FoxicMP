# FoxicMP 1.9.1.75

Первый подготовленный выпуск FoxicMP на основе MPC-BE 1.9.1.

## Основные изменения

- Приложение, исполняемые файлы, библиотеки ресурсов и расширение оболочки получили отдельное имя FoxicMP.
- Настройки и пользовательские данные хранятся в каталоге программы; профиль отделён от MPC-BE и MPC-HC.
- При первом запуске можно добавить пункт FoxicMP в контекстное меню видеофайлов.
- В разделе «Форматы» добавлены управление этим пунктом и проверка корректности пути при запуске.
- Нижняя панель объединяет элементы управления и сведения из строки состояния.
- Метки глав отображаются тонкими вертикальными линиями цвета RGB(94, 99, 104) по всей высоте шкалы времени.
- При наведении на шкалу отображаются номер и название главы.
- Добавлены собственные значки, логотип и профиль настроек по умолчанию.

## Файлы выпуска

- `FoxicMP.1.9.1.75*.x64-installer.zip` — установщик x64 в ZIP-архиве.
- `FoxicMP.1.9.1.75*.x64.7z` — portable-пакет x64.
- `FoxicMP.1.9.1.75*.x64.zip` — portable-пакет x64 в формате ZIP.
- `FoxicMP.1.9.1.75.checksums.sha256` — контрольные суммы SHA-256.

Бинарные файлы не имеют цифровой подписи издателя. Исходный код и производные сборки распространяются по GNU GPL v3.

This is the first prepared FoxicMP release, based on MPC-BE 1.9.1. It introduces a separate application identity, a portable per-program profile, optional video context-menu integration, a compact merged control/status bar, and full-height chapter markers. The binaries are not code-signed. Source code and derived builds are distributed under GNU GPL v3.
