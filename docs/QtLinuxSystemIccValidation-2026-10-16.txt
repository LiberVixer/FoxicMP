FoxicMP Qt Linux 0.1.31 — автоматический ICC в X11, пункт 15
Дата: 16 октября 2026. Ветка codex/linux-qt.

Ctrl+Alt+V → Видео — ICC-профиль → ICC enabled + источник system.
По умолчанию ICC off, источник manual; существующий ручной профиль сохранён.
Backend: colord, системная D-Bus, точный XRANDR_name текущего QWindow::screen.
Enabled=true, Kind=display, Owner=current uid либо system, Metadata name checked.
GetProfileForQualifiers(["*"]) выбирает default и соблюдает profiling inhibit;
Profiles[0] не используется. Только read-only методы, без смены desktop profile,
калибровки/разрешений. D-Bus может обычным образом активировать установленную
службу colord. Устанавливать/настраивать colord эта задача не пыталась.

Асинхронные вызовы, локальный precise deadline 1500 ms на каждый вызов.
Локальный precise timer ограничивает ожидание независимо от проверки timeout
в Qt/D-Bus. Поздний ответ после deadline не применяется.
Generation отбрасывает ответы старого экрана/режима. QWindow::screenChanged и
резервный опрос 500 ms, изменения системного профиля/байтов раз в 5 секунд.
При смене экрана старый ICC снимается сразу; нет fallback на другой монитор.
Ошибка, inhibit, отсутствие, недоступный/неверный ICC → native ICC clear + статус.

Системный файл только читается; RGB display <=16 MiB проверяется LittleCMS и
копируется в ColorProfiles/<SHA256>.icc рядом с приложением. Дедуп по байтам.
Автоматический путь не пишется в INI, manual video/iccProfile не заменяется.
Постоянный режим video/iccSource=manual/system, master video/iccEnabled.
Cancel не применяет новый выбор, reset возвращает defaults и не удаляет копии.
icc-profile-auto=false, icc-cache=false, intent общий, преобразование libmpv GL.
В Software сохранены настройки/диагностика без ICC-преобразования.
Wayland автоматический режим обходит запрос, показывает ручной fallback;
протокол управления цветом композитора ещё не реализован.

Реальная установленная colord доступна: display devices Virtual1/2/3.
У Virtual1 нет активного профиля: GetProfileForQualifiers(["*"]) возвращает
NothingMatched. Назначения не создавались, работа с реальным ICC монитора
не подтверждена. Автотесты и снимок Xvfb не доказывают цвет на физическом GPU,
перенос между реальными мониторами, VSync/tearing или Wayland color management.
