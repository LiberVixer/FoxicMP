# Проверка сегментных VP9 и Opus — 30 октября 2026

SDK 1.36. Проверены Linux Qt, Windows Qt и Classic. Harvester и установленные
Windows-приложения не менялись. AAC-образец — mono 48000 Гц; Opus — mono/stereo
48000 Гц. Каждый сценарий проверяет просмотр до полной загрузки, пропуск сегмента,
паузу при update, перемотку к 2 с, возобновление, ожидание хвоста, complete/EOF
и освобождение readers с одним readerId на цикл.

меняющиеся кадры, codec/pixel format, 10-bit там, где он задан, audio codec,
48000 Гц и фактическое число каналов. Classic проходит тот же цикл через
DirectShow с чтением обеих дорожек. Физический A/V drift, GPU и HDR не измерялись.

## Проверки, исходные ошибки и повторы

Native stream — 295 случаев на каждой ОС, exit 0: прежние кодеки и новые
VP9/Opus, auto-detection, ложные hints, неверные vpcC/dOps, pre-skip/edit,
диапазоны, SHA-256, усечение, отмена и последний владелец ресурсов.
Media regression — 468/468 на каждой ОС; single-segment native — 18/18.
Диагностический IPC — по 12 сценариев во всех трёх редакциях. Его публичный
H.264/AAC-профиль не расширялся.

Первый Linux CTest — 8/9 групп, exit 8; Windows — 9/10, exit 8. Семь новых
AAC channel-count assertions ошибочно ожидали stereo при mono-фикстуре.
В Linux вся data-driven функция дополнительно достигла стандартного watchdog
300 с после пяти успешных Opus-вариантов. Исправлено ожидание AAC=1; длительному
общему тесту задан QTEST_FUNCTION_TIMEOUT=1200000 мс и внешний предел 1500 с.

Повторены исправленные AAC-сценарии и оставшиеся Linux Opus: Linux 10 rows
(12 результатов с init/cleanup), Windows 7 rows (9 результатов), exit 0.
Уже прошедшие Opus-сценарии сохранены из первого прогона; каждый из 15 вариантов
имеет положительный результат на каждой ОС. Native и остальные группы повторно
без причины не запускались. Первые ненулевые exit codes сохранены в JSON.

Прежние v1 writer и scalar VP9 10-bit + Opus: по 4 Qt результата с init/cleanup,
exit 0 на обеих ОС. Classic v1 sessionDirectory также прошёл. Python SDK — 19/19,
family contract — 2/2. Все окончательные обязательные проверки — exit 0.

Поле producerChannelExpectation в машинном отчёте сохраняет первоначальное
ожидание producer; fixtureChannels указывает проверенный вход. Для AAC часть
первоначальных отчётов Classic содержит старое ожидание 2, а сама фикстура mono.
Фактическое число декодированных каналов проверено Qt и вынесено отдельно.
