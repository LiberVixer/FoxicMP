# Фактические metadata в UI — проверка SDK 1.27, 29 октября 2026

В SDK 1.26 metadata попадала в status, но прежний тест не проверял фактические
пункты меню и линии. Найдено перезаписывание глав списком декодера в Qt,
отсутствие очистки пустого списка и повторного применения revision 1 в Classic,
а также отсутствие применения title. Исправлены эти переходы и fallback к
названию start-запроса. Настройки пользователя сохраняются.

| Редакция | Проверка | Результат / exit code |
|---|---|---|
| Linux Qt | metadata UI, обычные window-title и playlists, confirmed-seek | 4/4 CTest, 35 QtTest результатов с init/cleanup, 0 |
| Windows Qt | metadata UI и confirmed-seek | 2/2 CTest, 16 QtTest результатов с init/cleanup, 0 |
| Windows Classic | Приём → поздние главы → команда главы → два отказа невалидной metadata → очистка → удаление title → возврат глав → второй сеанс с revision 1 | PASS, 0 |
| Общий native media corpus | Действующая codec/ResourceSource-матрица | 463/463, 0 |
| Семейный контракт | Каталог команд и независимость редакций | PASS, 0 |

Qt проверяет реальный QMenu, заголовок окна и пиксели тонкой вертикальной
линии (94,99,104) до/после очистки; главы переживают события chapter-list.
Classic проверяет содержимое UI chapter bag, переход через штатную команду
4401 и реальный текст HWND. TitleBarText=2 задан только в тестовом INI:
пользовательский режим имени файла/полного пути сохраняется. Профиль тестовой
копии создан до первого запуска с ContextMenuPrompted=1, ContextMenuEnabled=0.
Команды/иконки установленного Classic в HKCU до и после совпали.
Одноразовая тестовая задача и временная копия удалены, хеш EXE совпал с проверенным.

Linux установлен атомарно. INI SHA-256 до/после:
`ee2a51243880e578a7b1f38a0278ed178d1e2e379ba0f4f756b5f77427ac24b6`.
Проверены все 100 прежних файлов; предыдущий EXE сохранён для отката.
Windows-установки и YouTubeHarvester не изменялись.

Выбранная частично скачанная optional audio остаётся следующим этапом;
полная изоляция уже активного audio, cover/HLS/DASH/live этим исправлением
не реализованы. Проверки физических устройств и Wayland не выполнялись.
