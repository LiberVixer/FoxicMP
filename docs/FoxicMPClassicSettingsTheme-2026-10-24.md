# Classic: тёмная тема настроек — 24 октября 2026

## Поведение

Окно настроек использует существующий `Theme/UseDarkTheme` Classic. В тёмном
режиме меняются фон, дерево, заголовок страницы и окна, поля, списки с шапками,
кнопки, флажки, переключатели и ползунки. Светлый режим сохраняет штатное
оформление. После «Применить» уже открытое окно переключает тему.

`SettingsTheme.cpp` ограничивает оформление окнами настроек; глобальная тема
Windows и плеер Qt не меняются. `PPageBase` подключает оформление создаваемых
страниц, `PPageSheet` сохраняет штатный TreePropSheet с тёмным цветом рамки
страницы. Сохраняются 26 страниц, их порядок, ресурсы перевода, обработчики
управления, цветовые образцы и предупреждения о конфликтах клавиш. В режиме
высокой контрастности используется системное оформление. Специальные старые
системные полосы прокрутки и рамки отдельных native-контролов остаются нативными.

## Проверка Windows x64

MSBuild Release x64: итоговый exit **0**. Первый compile остановился на неявных
min/max; после исправления использованы `std::min/std::max`. Визуальные проверки
выявили выключенную системную рамку, белые строки таблицы клавиш и избыточную
перерисовку дерева при смене страницы; в итоговой сборке исправлены.

Воспроизводимый UI-harness: `tests/windows/classic_settings_theme.ps1`.
Запускается однократно в интерактивной 64-битной Windows-сессии с отдельными EXE
и INI. Параметры: Executable, SourceProfile, RussianLanguageDll, новый ReportRoot.

Итоговый прогон:

- **26** штатных русских имён страниц сохранены; **24** страницы открыты и сняты
  в тёмном режиме. DVD/захват пропущены согласно отложенным направлениям.
- Переключение dark → light → dark через штатный Apply, на страницах
  «Проигрыватель» и «Интерфейс»: **PASS**. Проверена яркость фона на снимках.
- На 24 снимках тёмных страниц контрольный пиксель фона **RGB 32/36/40**.
  Вручную просмотрены общая страница, интерфейс, таблица клавиш и светлый режим.
- Процесс плеера exit **0**, harness exit **0**, одноразовая Scheduled Task
  `FoxicMPClassicDarkOnce` результат **0**, после проверки удалена.
- SHA-256 установленного INI до/после совпал; полный снимок существующих команд
  и иконок контекстного меню Classic до/после финального теста совпал.

Промежуточный Apply-тест после посещения «Форматов» удалил пункты Classic из
HKCU: эта старая страница безусловно применяет регистрацию из тестового профиля.
79 исходных записей немедленно восстановлены с правильным установленным путём.
Финальный harness выполняет Apply **до создания «Форматов»**, после её посещения
использует только Cancel. Это правило закреплено в AGENTS.md. Установленный INI
не менялся и в промежуточном прогоне. Изменение самой регистрации/ассоциаций
не входит в реализацию темы.

## Дополнение: полосы прокрутки и вкладки

По следующему запросу добавлены тёмные полосы прокрутки и рамки дочерних
контролов окна настроек, отрисовка тёмных вкладок `SysTabControl32`, а также
отдельная отрисовка owner-draw списка «Встроенные фильтры». Это покрывает

системные элементы.

Windows Release-сборка с этими изменениями завершилась exit **0**. Обновлённый
harness снимает страницы 2, 16 и 22 в обеих темах. Финальный интерактивный прогон
не выполнен, потому что в момент проверки уже работал пользовательский Classic
с видео; тест не стал перехватывать его окно и был удалён вместе с одноразовой
задачей. Установленный EXE не заменялся поверх просмотра. Поэтому текущий EXE
на компьютере остаётся предыдущей проверенной сборкой 1.9.1.75 build 261024-1354;
новая сборка будет установлена после завершения текущего просмотра.
