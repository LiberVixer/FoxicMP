# Проверка модели постраничного каталога — 30 октября 2026

Проверена [внутренняя модель](ProgressiveSegmentCatalog.md), а не playback
длинных роликов. [Машинный отчёт](ProgressiveSegmentCatalogValidation-2026-10-30.json)
содержит список сценариев, SHA исходников и точные exit codes.

| Среда | Каталог | Прежняя модель / сегменты | Результат |
|---|---:|---:|---|
| Linux, GCC | 51 сценарий | 90 + 11 | CTest 3/3, exit 0 |
| Windows, MinGW GCC (Qt toolchain) | те же 51 | 90 + 11 | CTest 3/3, exit 0 |
| Windows, MSVC x64 (Classic toolchain) | те же 51 | отдельно не повторялись | native runner, exit 0 |

На трёх компиляторах получен одинаковый отчёт каталога. Проверены 8192 ресурса
с учётом init, предел 4096 сегментов на дорожку, 64 KiB на страницу, точное
время выше 2^53, длина/SHA страницы и session/generation/writer identity.
Проверены некорректные пути, неизвестные/дублирующиеся поля и ссылки, неполные
или retired ресурсы, Unicode и вложенный NUL, перенос inline-хвоста в страницу,
добавление страниц, запрет подмены/удаления опубликованных страниц и сохранение
активной модели после отклонённого обновления.

Первые попытки выявили ошибку компиляции нового тестового CLI, прежний предел
128 элементов в структурной проверке раскрытого JSON и неверно меняющую
известную длительность тестовую фикстуру. Они исправлены; до исправления
последней CTest возвращал exit 8, MSVC Python runner — exit 1.
Неудачные попытки не представлены как успешные проверки приложения.

Прежний публичный parser по-прежнему отклоняет каталог и сохраняет ограничения
64 KiB / 64 ресурса. Новых capability, SDK-релиза и приложения с поддержкой
каталога пока нет. Медиадекодеры, A/V sync, long playback, I/O adapter и
ограничение числа открытых файлов этим прогоном **не проверены**.

Установленная Linux-программа остаётся проверенной сборкой SDK 1.36;
SHA EXE сверён, замена не выполнялась. Профили и Windows-установки не менялись.
Тесты чистой модели не открывают медиа и не обращаются к окнам, аудиосеансу,
HKCU, файловому registry читателей или Harvester. Одноразовые Windows tasks
и периодические проверки не создавались.
