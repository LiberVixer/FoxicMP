FoxicMP Qt 0.1.17 — пункт 10: оформление, OSD и превью
Дата: 2026-10-15. Linux Mint 22.3 x64, Qt 6.4.2, libmpv 0.37.0,
FFmpeg/FFprobe 6.1.1. Изолированные Xvfb/Mesa llvmpipe; запрошенный OpenGL

Оформление и язык
-----------------
Тёмная FoxicMP, светлая, системная, свои цвета. Фон/текст/выделение,
цвет пройденной части таймлайна; линии глав сохранили RGB 94/99/104 и ширину
1 логический пиксель. Значки 12–48 логических пикселей (20 по умолчанию),
кнопка icon+10 × icon+8, вертикальные поля панели 3+3. Шрифт/размер плейлиста
применяются также к новым вкладкам. Пользовательские цвета/имена не исполняются
как CSS: цвета проверяются QColor, коды формируются из QColor::name().

Логотип и панель из локального изображения. Путь относителен папке программы;
пустой, недоступный, неподходящий или слишком большой файл заменяется встроенным.
4096 пикселей на сторону / 16 млн пикселей. PNG/BMP-панель: 10 квадратных ячеек
play,pause,stop,previous,next,frame,playlist,open,volume,mute; также 15/16 Classic.
Classic mapping из PlayerToolBar/mplayerc.rc: play0,pause1,stop2,previous4,next5,
frame6,open7,volume12,mute13. Непредставленные ячейки — встроенные значки.
Неальфа magenta/classic-gray BMP фон становится прозрачным. Произвольный skin
или SVG-пакет Classic не интерпретируется.

Русский/English после перезапуска. QCoreApplication::translate через QTranslator
с JSON-каталогом; 663 записи, 654 текущих исходных строк покрыты проверкой.
Внешний JSON-пакет translations: исходный русский текст → строка перевода.
Лимит 2 МиБ, подстановки %1/%n должны сохраняться; неверный пакет отклоняется,
UI возвращается к исходному русскому. Имена файлов, пользовательские названия
вкладок/избранного не переводятся. Стандартные Qt-диалоги используют установленный
qtbase_ru, если доступен. Каталог English включён и в ресурс, и как пример
translations/en.json в архив. CLI --version/--help не создают INI.

OSD
---
Qt QLabel subclass с собственным QPainter: шрифт/размер 10–72 логических пикселя,
цвет текста/фона/рамки, непрозрачность фона 0–255, рамка 0–8, тень,
сглаживание, сообщение 200–10000 мс (1600 по умолчанию). Постоянные имя,
позиция/длительность и часы имеют отдельные переключатели, по умолчанию выключены.
Общий выключатель ui/osd сохранён. Имя/позиция — при открытом источнике,
часы возможны и в idle. Наложения не меняют скриншот/subtitle pipeline libmpv.
Расположение и ограничение ширины учитывают доступную видеообласть; текст PlainText.

Превью
------
5–50% рабочей области текущего экрана, по умолчанию 25%; предел 160–960
логических пикселей. Изображение сохраняет аспект и текущие фильтры/поворот.
Отдельный ffmpeg, debounce 180 мс, отмена и поколения исключают устаревший ответ.
Кэш изображений до 16 МиБ. Локальная идентичность: путь/размер/mtime/время/фильтры;
смена размера/параметров очищает кэш. Локальный decode deadline 3500 мс.

Онлайн-превью явно включается preview/online=false по умолчанию. HTTP(S) direct
и веб-страницы; настроенный yt-dlp --ignore-config сначала получает медиаадрес,
затем ffmpeg отдельно читает кадр. Только HTTP(S) адрес извлечения, без file/av
и других протоколов. Whitelist входа сетевого декодера: HTTP(S)/TCP/TLS/crypto/
HTTP proxy, без локальных файлов. User-Agent и избранные HTTP-заголовки проверены
на CR/LF/NUL и длину. Выбор небольшого качества по высоте превью (240–540),
с предпочтением H.264; не выбирается избыточный 720p для маленького окна.
Запросы hover одного источника разделяют незавершённое извлечение; после ответа
декодируется последнее выбранное время. Срок кэша media URL — 5 минут;
файлы PNG и история превью на диск не пишутся. Тайм-аут каждого этапа 1–20 с,
по умолчанию 10 с; максимальная суммарная задержка может включать оба этапа.
Растущие источники, live/неизвестная длительность и неподдерживаемые протоколы
в UI исключены. Основной Player не получает команд перемотки от превью.

Обычная отмена асинхронная; деструктор дожидается убитых дочерних QProcess,
чтобы не оставлять ffmpeg и предупреждение о работающем процессе при закрытии.
Зависший HTTP работник уничтожен, PID проверен kill(pid,0) → ESRCH.

главный Player остаётся на паузе/1.0с при preview6.0с; размер окна превью по экрану;
extractor-path с пробелами, coalescing → один запрос/последнее время,
отклонение file:/// URL и CRLF заголовка; Cancel/Apply, live appearance и язык
только после нового Window; реальные screenshots.

Первая предварительная проверка QColor дала одинаковый #ARGB при различной
внутренней точности HSV/RGB; критерий исправлен на отображаемый rgba8.
Пустые внешние пути больше не вызывают QFSFileEngine warnings. При реальном
сетевом timeout обнаружен QProcess destructor warning; исправлена синхронизация
уничтожения и добавлен тест PID. После исправления общий прогон повторён.
После общего прогона шаблон команды Nemo исключён из переводимых строк:
языковой пакет меняет подписи, но не шаблон запуска. На финальных бинарниках
повторены integration/desktopLaunch (4 passed) и весь appearance (9 passed),
включая внешний пакет со строкой, похожей на шаблон Nemo. Ошибок нет.
Один программный прогон был прерван SIGTERM с потерей X11-сеанса :186,
без провала утверждений QtTest до разрыва; повторён с новым Xvfb :193.
Причина внешнего завершения X-сервера не установлена; итоговые результаты выше.

Визуальная сверка
-----------------

Qt classic-layout.png (1060x680, пример значков16). Общий FoxicMP логотип,

Wayland и другие оконные менеджеры остаются отдельной проверкой.
