# FoxiqMP qt — пакет Debian / Linux Mint

Пакет `foxiqmp-qt_0.2.0-1_amd64.deb` предназначен для Linux Mint 22.x x64
(база Ubuntu 24.04). Установка с зависимостями:

```sh
sudo apt install ./foxiqmp-qt_0.2.0-1_amd64.deb
```

Запуск из меню или командой `foxiqmp-qt`. При первом запуске системный payload
из `/usr/lib/foxiqmp-qt` копируется в `~/.local/opt/FoxiqMP-qt`. EXE Linux,
`FoxicMPQt.ini`, история и личные файлы находятся вместе в этой доступной
для записи папке программы. Установщик не создаёт файлы в домашней папке от
root; пользовательская копия создаётся при запуске самим пользователем.

При обновлении только поставляемые файлы заменяются атомарно, INI и личные
данные остаются. Удаление `.deb` удаляет системные файлы и ярлык, но сохраняет
пользовательскую папку программы. Portable-копии и их профили не затрагиваются.
`--profile ПУТЬ` по-прежнему позволяет явно выбрать другой профиль.

Пакет добавляет приложение в меню и «Открыть с помощью», не переназначая
видеофайлы по умолчанию. Зависимости ELF берутся из `dpkg-shlibdeps` на сборочной
системе. Сборка из подготовленного CMake install:

```sh
python3 qt/packaging/debian/build.py --stage /путь/к/чистой/portable-папке --output build/release
```
